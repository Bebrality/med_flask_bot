# 💊 Medicine Reminder Bot

Веб-приложение для управления приёмом лекарств с напоминаниями по времени.

---

## 🚀 Возможности

- ➕ Добавление лекарств
- ❌ Удаление по отдельности
- 🗑 Очистка всего списка
- ✔ Отметка "принято"
- 🔄 Автообновление без перезагрузки
- 🔔 Уведомления по времени
- 🔊 Звуковое оповещение
- 🤖 Простой чат-бот

---

## 🧠 Как работает

Приложение состоит из:

- **Backend (Flask)** — обрабатывает запросы
- **Frontend (HTML + CSS + JS)** — интерфейс
- **JSON файл** — хранение данных

Связь происходит через `fetch` (HTTP-запросы).
